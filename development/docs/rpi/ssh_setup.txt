SSH / VNC Quick Notes
=====================

Start the Windows SSH agent if needed:

Get-Service ssh-agent
Start-Service ssh-agent
Set-Service -Name ssh-agent -StartupType Automatic

Connect to a Pi:

ssh pi@100.111.162.21

Run the app on the Pi:

cd ~/drx-2.0/main
python3 kneespa.py

Start x11vnc from an RDP or local desktop session:

x11vnc -display :0 -auth guess -forever -loop -noxdamage -repeat -rfbauth ~/.vnc/passwd -rfbport 5900 -shared
